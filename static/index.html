ABOUT THE PROJECT

Educational ML-assisted clinical decision support

MediSafe AI is a final-year academic project that demonstrates a web-based drug interaction screening workflow. It combines a local curated interaction dataset, structured drug-risk features, a trained machine-learning model, human-readable explanations, and SQLite-based alert history.
